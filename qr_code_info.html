🎯 Multi-Location Hotspot System

✅ Implementation Complete!
Your AR hotspot system now supports multiple scanning locations with different hotspot positions.

📋 How It Works

The system uses URL parameters to determine which hotspot configuration to load:

  • No parameter: Loads default configuration
  • ?location=stairs: Loads stairs-specific positions
  • ?location=balcony: Loads balcony-specific positions

📱 QR Code Implementation

To generate QR codes for these locations:

  1. Use any QR code generator (Google "QR code generator")
  2. Input the URLs above
  3. Print the QR codes
  4. Place them at the corresponding physical locations

Recommended QR code generators:

  • qr-code-generator.com
  • qrcode-monkey.com

🔧 Customizing Positions

To adjust hotspot positions for each location:

  1. Edit Scripts/hotspotsConfig-stairs.json for stairs positions
  2. Edit Scripts/hotspotsConfig-balcony.json for balcony positions
  3. Adjust the fixedAngleDegrees, initialY, and initialZ values
  4. Test the changes using the URLs above
